# Module 25.2 — 50 Senior & Staff Engineer Technical Interview Questions

## 1. JAVASCRIPT & RUNTIME FOUNDATIONS (Q1–Q8)
1. **Explain the microtask vs macrotask execution order in the browser event loop.**  
   *Answer:* All microtasks (`Promise.then`, `queueMicrotask`, `MutationObserver`) must be completely drained before the browser picks the next macrotask (`setTimeout`, `setInterval`, I/O) or executes a render step.
2. **Why does mutating an object directly break React shallow equality checks?**  
   *Answer:* React compares previous and next state references using `Object.is()`. Direct mutations keep the exact same memory address pointer, so React concludes no state changed and skips re-rendering.
3. **What is a "stale closure" in JavaScript and how does it manifest in `useEffect`?**  
   *Answer:* A closure that captures variable values from an older render cycle because the effect dependency array omitted that variable or failed to refresh.
4. **How does `AbortController` prevent async race conditions in React?**  
   *Answer:* It allows canceling outgoing HTTP requests when a user rapidly changes search inputs or unmounts a component, ensuring outdated responses are discarded.

## 2. REACT 19 & FIBER INTERNALS (Q9–Q18)
5. **What is a Fiber node and what information does it store?**  
   *Answer:* A lightweight plain JS object representing a unit of work; stores element type, props, state queue, pointers (`child`, `sibling`, `return`), effect tags, and alternate work-in-progress tree pointers.
6. **Explain the difference between Concurrent Mode Transitions (`startTransition`) and standard state updates.**  
   *Answer:* Standard updates are urgent and interrupt rendering immediately. Transitions are non-urgent, run at lower lane priorities, and yield control to user typing/clicks to prevent UI lag.
7. **What is the difference between `useLayoutEffect` and `useEffect`?**  
   *Answer:* `useLayoutEffect` runs synchronously *before* the browser paints (blocking paint to measure DOM layout); `useEffect` runs asynchronously *after* paint.
8. **Why was `useSyncExternalStore` introduced in React 18?**  
   *Answer:* To prevent "tearing" (inconsistent UI reads from external stores) during concurrent rendering by providing a synchronous subscription mechanism.

## 3. FULL-STACK SPRING BOOT 3 INTEGRATION (Q19–Q30)
9. **Why does 64-bit Java `Long` primary keys truncate in JavaScript?**  
   *Answer:* JavaScript's `Number.MAX_SAFE_INTEGER` is $2^{53}-1$. 64-bit Longs exceed this and lose precision unless serialized as Strings via `@JsonSerialize(using = ToStringSerializer.class)`.
10. **Why must Spring's `CorsFilter` run before `SecurityFilterChain` authentication filters?**  
    *Answer:* Preflight `OPTIONS` requests carry no auth credentials. If auth filters run first, they reject preflights with `403 Forbidden`, blocking the browser from dispatching the real request.
11. **How do you implement optimistic concurrency control across React and Spring JPA?**  
    *Answer:* Spring entity has `@Version private Long version;`. React sends `If-Match: version` header. If version is stale, Spring throws 409 Conflict; React rolls back optimistic UI state.

## 4. PERFORMANCE, SECURITY & ARCHITECTURE (Q31–Q50)
12. **How does DOM Virtualization maintain 60fps with 100,000 table rows?**  
    *Answer:* It calculates scroll offset and renders only the visible window ($\sim 20$ rows) inside a tall spacer element, keeping total DOM nodes under 100.
13. **Why does `dangerouslySetInnerHTML` require DOMPurify rather than regular expressions?**  
    *Answer:* Regex filters cannot handle malformed HTML, nested tags, or obfuscated event handlers (`<svg/onload=...>`). DOMPurify constructs a full DOM tree to whitelist safe nodes.
14. **How do you pass runtime environment variables to containerized React Docker images?**  
    *Answer:* Inject a dynamic `window.__RUNTIME_CONFIG__` file generated by `docker-entrypoint.sh` at container boot, avoiding build-time static embedding.
15. **What is the W3C `traceparent` distributed tracing standard format?**  
    *Answer:* `00-[32-hex-trace-id]-[16-hex-span-id]-[flags]` propagated in HTTP headers from React to Spring Boot OpenTelemetry collectors.
